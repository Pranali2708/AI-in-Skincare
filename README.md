# AI-in-Skincare
This project aims to create a dynamic web application that suggests individualized skincare routines based on real-time skin type identification and user preferences. Utilizing deep learning models, specifically Convolutional Neural Networks (CNNs), the application classifies user-uploaded facial images or image taken by webeam into skin types like Oily. Normal to Dry. Acne-Prone, and Combination. Along with skin analysis, the system also takes user-specific parameters such age group and budget limitations, allowing for highly personalized product suggestions. Methodology of the project includes data fetching, image preprocessing, training of a model with TensorFlow, and implementation of a product recommendation system based on filtering parameters like skin type, age, product category, and price range. Combination skin types are given special treatment by intelligently combining products across different categories.
